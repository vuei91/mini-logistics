# 회원 인증·인가 구현 체크리스트

## 1. 계정 도메인

- [x] 화주(`Shipper`) 로그인 식별자: 이메일·비밀번호 해시 필드 추가
- [x] 화주 가입 시 이메일 소문자 정규화
- [x] 차주(`Driver`) 로그인 식별자: 이메일·비밀번호 해시 필드 추가
- [x] 이메일 중복 방지: 화주·차주 각각 고유성 검증
- [x] 비밀번호 평문 미저장: BCrypt 해시 적용

## 2. 가입·로그인 API

- [x] `POST /auth/shippers/signup`
- [x] `POST /auth/drivers/signup`
- [x] `POST /auth/shippers/login`
- [x] `POST /auth/drivers/login`
- [x] 유효성 오류는 400, 중복 이메일은 409, 잘못된 자격증명은 401

## 3. JWT 인증

- [x] JWT에 회원 유형, 프로필 ID, 만료 시각 포함
- [x] 로그인 성공 시 Bearer 토큰 반환
- [x] Bearer 토큰 검증 필터
- [x] 만료·변조·누락 토큰은 401
- [x] 비밀키와 만료 시간은 환경 설정으로 분리

## 4. API 권한·소유권

- [x] 화주만 운송 요청 생성 가능
- [x] 화주는 자신의 운송 요청만 조회·취소 가능
- [x] 차주만 배차 수락·거절·운송 상태 변경 가능
- [x] 차주는 본인에게 제안된 배차만 조작 가능
- [x] Swagger·로그인·가입 엔드포인트는 인증 없이 접근 가능

## 5. 검증

- [x] 가입/로그인 단위·컨트롤러 테스트
- [x] JWT 발급·만료·변조 테스트
- [x] 역할·소유권별 401/403 통합 테스트
- [x] 전체 Gradle 테스트 통과
